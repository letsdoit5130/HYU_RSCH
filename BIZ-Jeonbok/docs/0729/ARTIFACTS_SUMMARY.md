# 완도 전복 글로벌 무역 5대 최종 산출물 Summary

## 1. 산출물 개요
완도 전복 글로벌 15대 유망국가(홍콩, 싱가포르, 베트남, 마카오, 대만, 말레이시아, 태국, 미국, 캐나다, 호주, 일본, 프랑스, 네덜란드, 독일, 영국) 825개 파트너 기업의 24대 증빙/검증 표준 컬럼 데이터셋이 실시간 반영된 5대 통합 산출물입니다.
