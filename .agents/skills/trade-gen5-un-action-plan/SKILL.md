# 🗺️ Trade Action Plan Generator (실행 로드맵 생성 스킬)

`trade-gen1-un-eda`가 만든 EDA 리포트를 파싱해, "무엇을, 왜, 언제까지, 실패하면 어떻게"가 전부 갖춰진
**체크리스트형 실행 로드맵**을 자동 생성합니다. 5단계 파이프라인의 마지막 단계입니다 — 전체 흐름은
[`../trade-gen-docs/README.md`](../trade-gen-docs/README.md) 참고.

---

## 🛠️ 스킬 사용법 (Usage)

**사전 조건**: 먼저 `trade-gen1-un-eda`로 해당 품목의 EDA 리포트를 생성해야 합니다.

```bash
uv run python .agents/skills/trade-gen5-un-action-plan/scripts/generate_action_plan.py \
  --item "전복 (Abalone)" \
  --output_dir BIZ-ABALONE \
  --home_country "Korea"
```

### 입력 파라미터
- `--item` (필수): 품목명. `trade-gen1-un-eda`에 넘긴 값과 동일해야 합니다.
- `--output_dir` (필수): 프로젝트 루트 폴더. `reports/` 하위에 결과가 저장됩니다.
- `--eda_report` (선택): 참조할 EDA 리포트 경로 (생략 시 자동 탐색).
- `--item_slug` (선택): 파일명 슬러그.
- `--home_country` (선택, 기본값 `Korea`): 표시용 자국명.

### 출력
`{output_dir}/reports/{품목}_Action_Plan.md` — 체크박스 기반 실행 로드맵.

## 📋 로드맵 구성 (사용자 피드백 6가지 반영)

| # | 구성 요소 | 무엇을 반영했나 |
|---|---|---|
| 0 | 사전 준비 서류 체크리스트 | 원산지증명서/위생증명서/HACCP·COA/Sales Contract 등 — 로드맵 시작 전 1회 준비 |
| 1 | 시장 개척 스텝 (우선 개척 시장 3선당 1개) | EDA의 ①②③ 시장·추천품목·근거를 그대로 스텝화 |
| 2 | **목표 완료일** | EDA 05번 차트(월별 계절성)에서 피크월을 찾아 리드타임(기본 3개월)을 역산. 계절성 데이터가 없으면 "가능한 빨리" 폴백 |
| 3 | **실패 시 대안(Plan B)** | 3선/삼국무역 3선 자체가 이미 우선순위 리스트이므로, 현재 스텝 실패 시 다음 순위 픽으로 자동 전환 |
| 4 | **자금 계획** | 오퍼서 템플릿의 결제조건(T/T 30/70 등) 기준으로 자금 묶이는 기간을 안내. 삼국무역은 매입/판매 결제조건 불일치 리스크까지 별도 경고 |
| 5 | **샘플/인증서 검증 게이트** | 계약(본오더) 전에 반드시 통과해야 하는 체크박스로 강제 — 생략 시 리스크 명시 |
| 6 | 삼국무역 실행 스텝 (조합 3선당 1개) | B측 컨택 파트너, 권장 매입가/판매가, FTA 미적용·중계무역 신고·제재국 확인 항목 포함 |
| 7 | **로드맵 갱신 트리거** | 3개월 경과/데이터 재수집/가격 괴리/시장 구조 변화 시 재생성 안내 |

## 🔁 재실행 안전성 (State 보존)

기존 `{품목}_Action_Plan.md`가 있으면, 이미 사람이 `- [x]`로 체크한 라인은 재생성 후에도
동일 텍스트 라인에 그대로 유지됩니다 (`preserve_checked_items()`). 즉 EDA를 재수집해서 로드맵을
다시 만들어도 진행 상황을 잃지 않습니다.

## 💬 세션 내 진행 방식

"1번 끝났어" / "다음 스텝 진행해줘"라고 말하면, AI 에이전트가 `{품목}_Action_Plan.md`를 다시 읽어
아직 `[ ]`로 남은 첫 스텝을 찾아 안내하도록 설계돼 있습니다 (이 스킬 자체는 상태를 자동으로
체크하지 않으며, 대화 세션에서 파일을 읽고 다음 액션을 안내하는 것은 AI 에이전트의 역할입니다).

## ⚠️ 이 스킬이 하지 않는 것

- 실제 웹 검색/실사를 하지 않습니다. "B측 컨택 파트너"는 실제 회사명이 아니라 조사를 지시하는
  템플릿(`*(실사 확인 필요)*`)입니다.
- 결제조건/리드타임(LCL 30~45일 등)은 업계 일반 표준치이며, 품목·항로별 정확한 값은 별도 확인이
  필요합니다.
- 계절성 데이터가 없는 EDA 리포트(연간 집계만 있는 경우)에서는 목표일을 계산하지 않고 명시적으로
  "데이터 없음"을 표시합니다 (지어내지 않음).
