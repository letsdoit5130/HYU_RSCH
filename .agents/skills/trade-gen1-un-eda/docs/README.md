## 1. 파이프라인에서의 역할

`trade-gen1-un-eda`는 5단계 무역 파트너 발굴 파이프라인의 **1단계(입력 단계)**입니다.

```
[1] trade-gen1-un-eda  ← 지금 이 스킬
      │  (UN Comtrade CSV → EDA 리포트 + 17개 차트)
      ▼
[2] trade-gen2.1-un-sourcing
      │  (EDA 리포트 → 소싱 후보국 트래커)
      ▼
[2.2 / 4] 실제 파트너 검색 (대화형 또는 완전자동)
```

전체 5단계 흐름과 각 스킬을 언제 쓰는지는 종합 문서
[`../../trade-gen-docs/README.md`](../../trade-gen-docs/README.md)를 참고하세요.

**입력**: UN Comtrade(또는 호환 스키마) 무역 통계 CSV
**출력**: `{output_dir}/images/*.png`(17개 차트), `{output_dir}/reports/BIZ-{품목}_Gathered_EDA_Report.md`
**다음 단계가 읽는 파일**: 위 리포트 마크다운(특히 "TOP N HS Code별 TOP 10 유망 타겟시장 11대 명세 표")을
`trade-gen2.1-un-sourcing`이 파싱합니다.

## 3. 데이터 수집 시 유의할 점 (요약)

Export/Import를 나눠서 수집할 때 흔히 놓치는 함정 — 자세한 배경은 위 개정 이력 참고:

- **Import는 `reporter=all`** 로 수집해야 진짜 양자(bilateral) 데이터가 되고, `reporterDesc`(수입국)와
  `partnerDesc`(원산지)가 실제로 다양하게 채워집니다.
- **Export를 자국 단독으로 수집**하면 자국 벤치마크는 정확하지만, "글로벌 경쟁 수출국" 랭킹은
  간접 추정치에 머뭅니다. `reporter=all`로 확장하면 미보고국 사각지대도 줄고 미러 신뢰도 체크도
  가능해집니다.
- **최신 연도**는 Comtrade 보고 시차 때문에 보고국 수가 급감하는 게 정상이므로, 이 스크립트가
  자동으로 감지해 순위/성장률 계산에서 제외합니다 — 별도 조치 불필요.
